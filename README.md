# Doge Coin Empire 🐕

Мемный кликер-тайкун на Flask + SQLite. Майнь DogeCoin, прокачивай ферму, переживай крипто-события и стань межгалактическим майнером!

## 🚀 Быстрый старт

```bash
# 1. Клонируй репозиторий
git clone <url-репозитория>
cd doge-coin-empire

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Запусти сервер
python app.py
