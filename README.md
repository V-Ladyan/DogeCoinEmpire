## 2. 🎮 Что сделано

### 🔹 Основной сценарий

Игрок кликает по Doge, зарабатывает DogeCoin, покупает улучшения и проходит 5 этапов развития — от домашнего ноутбука до межгалактической майнинг-станции. Каждый этап динамически меняет фон, описание и открывает доступ к новым улучшениям.

### 🔹 5 этапов игры

| Этап | Название | Порог монет |
| :---: | :--- | :--- |
| **1** | 🖥️ Домашний майнер | `0` |
| **2** | 🏭 Гаражная ферма | `500` |
| **3** | 🏢 Промышленный майнинг | `5 000` |
| **4** | 🌕 Lunar Doge Station | `50 000` |
| **5** | 🚀 Межгалактический хайп | `500 000` |

### 🔹 7 улучшений (2 меняют механику)

| Улучшение | Что делает | Тип механики |
| :--- | :--- | :--- |
| 🎮 **Игровая видеокарта** | `+1` к силе клика | Числовой бонус |
| ⚡ **Энергетик "Doge Fuel"** | `10%` шанс критического удара `x3` | **Крит-система** 🔄 |
| 🤖 **Автокликер** | Автоматический клик каждую секунду | **Idle-механика** 💤 |
| ✨ **Магия мема** | Множитель всех доходов `x2` | Числовой бонус |
| 💎 **Квантовый майнер** | `50%` шанс `x10` к клику | Числовой бонус |
| ⏰ **Временная аномалия** | Ускоряет автоклик `x3` на 10 секунд | Числовой бонус |
| 🐕 **Армия Doge** | Тысячи сиба-ину майнят для тебя (`+50` к автоклику) | Числовой бонус |

> ⚙️ **Механики, меняющие геймплей:** 
> *   **Крит-система (Doge Fuel)** — добавляет шанс критического удара с увеличенным доходом и визуальным эффектом.
> *   **Idle-механика (Автокликер)** — добавляет пассивный доход, который работает постоянно, даже без кликов.

### 🔹 5 случайных событий
Срабатывают с вероятностью **15% при каждом клике**, мгновенно влияя на экономику:
* 🐦 **Твит Илона Маска** — Памп! `+30%` к текущему балансу.
* 🇨🇳 **Китай запретил майнинг** — Дамп... `-15%` монет.
* 🔥 **Мем стал вирусным** — Тотальный хайп! Множитель `x2` на 30 секунд.
* 👾 **Хакерская атака** — Дыра в безопасности. Потеря `-25%` монет.
* 🎁 **Таинственный сундук** — Удача майнера. Случайный джекпот.

## 3. 🧠 Как устроена логика

### 🔹 Core Loop (Основной игровой цикл)
```text
КЛИК 🖱️ ──> DOGECOIN 🪙 ──> УЛУЧШЕНИЯ ⬆️ ──> НОВЫЙ ЭТАП 🚀
         │                        │
         ├──> СЛУЧАЙНЫЕ СОБЫТИЯ 🎲  └──> МОНЕТИЗАЦИЯ 💎
```
*   **Клик** по Doge или кнопке — зарабатывай DogeCoin.
*   **Покупка улучшений** — инвестируй в апгрейды для роста эффективности.
*   **Прогресс стадий** — расширяй масштабы своей крипто-империи.
*   **Реакция на события** — лавируй среди твитов Илона и хакерских атак.
*   **Монетизация** — активируй бонусы и собирай премиум-коллекции.

### 🔹 Экономика
*   **Базовый клик:** Приносит `1` монету.
*   **Стоимость улучшений:** Рассчитывается по формуле `base_cost × (cost_multiplier ^ level)`. Каждое следующее улучшение дороже предыдущего.
*   **Пороги этапов:** Растут экспоненциально — каждый следующий этап требует в 10 раз больше монет.
*   **Автоклик:** Пассивный доход каждую секунду, даже когда игрок не кликает.
*   **Критические удары:** Случайные `x3` к клику добавляют нелинейность дохода.

## 4. 💾 Где хранятся данные

Вся информация записывается в локальную базу данных **SQLite** (`doge_empire.db`), которая создаётся автоматически при первом запуске игры. 

### 🔹 Структура таблиц:
*   `users` — баланс, количество кликов, текущий этап, множители, активный скин, streak дней.
*   `upgrades` — список купленных улучшений и их текущие уровни.
*   `events_log` — история всех игровых событий (твиты, атаки, бонусы).
*   `monetization_log` — история взаимодействия с монетизацией (бусты, награды, скины).

### 🔹 Как работает сохранение:
*   Данные игрока строго привязаны к текущей сессии через куки `user_id`.
*   Прогресс сохраняется автоматически при каждом клике, покупке и событии.
*   Прогресс **не теряется** при перезагрузке страницы или полном закрытии браузера.
*   При очистке cookie игра начинается заново *(в будущем можно доработать до полноценной системы логинов)*.

## 5. 💰 Где монетизация

В игре реализованы 3 популярные идеи монетизации (без реальной оплаты), для каждой из которых подобран коммерческий аналог:

1. 📺 **Рекламный буст** *(Доступен: с 1 этапа)*
   * **Как работает:** Игрок нажимает кнопку "посмотреть рекламу", запускается 5-секундный таймер в модальном окне, после чего активируется `x2` ко всем доходам на 30 секунд.
   * **Ограничение:** Кулдаун 5 минут между просмотрами.
   * **Реальный аналог:** *Rewarded Video Ads (AdMob, Unity Ads, Yandex Ads)*.

2. 🎁 **Ежедневные бонусы** *(Доступен: со 2 этапа)*
   * **Как работает:** Награда за вход в игру каждый день. Сумма увеличивается вместе с серией дней (streak). Базовая награда: `50 DogeCoin`. Множитель серии: `x1.5` за каждый день подряд (до 7 дней максимум).
   * **Реальный аналог:** *Daily Rewards для удержания пользователей (Retention)*.

3. 🎨 **Премиум-скины** *(Доступен: с 3 этапа)*
   * **Как работает:** Покупка кастомных визуальных скинов за игровую валюту. Каждый скин даёт постоянный пассивный множитель к кликам:
     * 🦊 *Golden Doge* — цена `5 000` монет, бонус `x1.1`
     * 🤖 *Cyber Doge* — цена `10 000` монет, бонус `x1.2`
     * 🌌 *Cosmic Doge* — цена `25 000` монет, бонус `x1.5`
   * **Реальный аналог:** *In-App Purchases (косметические предметы)*.

## 6. 🤖 Что использовали из AI

В процессе разработки активно применялись AI-инструменты для решения следующих задач:
*   **🏛️ Архитектурный рефакторинг:** Использование промптов для разделения монолитной структуры на изолированные слои бизнес-логики (`game_logic.py`), персистентности (`database.py`) и контроллеров (`app.py`), что минимизировало технический долг.
*   **⚖️ Верификация игрового баланса:** Генерация математических моделей для экспоненциального роста стоимости апгрейдов (`base_cost × (cost_multiplier ^ level)`) и валидация распределения вероятностей для 15%-го шанса триггера случайных ивентов.
*   **🐛 Локализация кроссбраузерных багов:** Диагностика и быстрое устранение специфических фронтенд-проблем (исправление конфликтов обработки событий клика в DOM, адаптация CSS-свойства `backdrop-filter` и добавление вендорных префиксов для корректного рендеринга модальных окон в мобильных версиях Safari/iOS).
*   **🧼 Оптимизация и чистка кода:** Проведение автоматизированного статического анализа кода для выявления и выноса устаревших inline-стилей во внешний файл конфигурации `style.css`.
*   **📝 Документирование систем:** Ускорение написания технической спецификации, схем Core Loop и структуры хранения данных СУБД для технической документации проекта.
